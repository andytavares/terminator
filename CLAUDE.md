# Project constitution

Follow the constitution at `docs/CONSTITUTION.md`. It governs every change in this codebase; deviating from it needs the user's explicit approval first.

# Pull request descriptions

Every pull request description has a `## Release notes` section, as in `.github/PULL_REQUEST_TEMPLATE.md`. The release job in `.github/workflows/ci.yml` publishes that section as the release notes. Write bullets for people who use the app, in plain words. Write "Internal changes only." when users see nothing new.
