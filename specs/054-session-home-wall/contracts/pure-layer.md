# Contract: pure layer

Everything a surface draws is computed by a pure function first, so each one is unit-testable at its boundaries and no component decides ordering, grouping or matching.

Renderer functions live in `src/renderer/sidebar/`, under the existing `purity.spec.ts` guard (no store, `window`, `document`, `localStorage` or `Date.now` imports). The two `load/save` preference pairs are the documented exception, the same as `loadHiddenLanes` today. They move out of the guarded list with a comment naming the side effect.

| Module                                    | Export                                                                          | Invariants                                                                                                                                                                                                                                    |
| ----------------------------------------- | ------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/shared/session-records/retention.ts` | `pruneRecords(records, now): SessionRecord[]`                                   | Keeps every open record. Keeps a closed record when `now − closedAt ≤ 30 days`, so day 30 is kept and day 30 + 1ms is dropped. Never reorders.                                                                                                |
| `sidebar/work-item.ts`                    | `resolveWorkItem(record, projectLink)`                                          | Session link wins. `null` only when both are absent.                                                                                                                                                                                          |
| `sidebar/session-facts.ts`                | `buildSessionFacts(sessions, records, projects, workspaces, projectLinks, now)` | Each open session appears exactly once. Closed records appear only when no open session has their id. A missing project yields a "No project" fact, not a dropped session.                                                                    |
| `sidebar/choice-prompt.ts`                | `parseChoicePrompt(lines: string[]): ChoicePrompt \| null`                      | See research R5. Requires ≥ 2 options numbered 1..n in order, in the bottom half of the lines. Otherwise `null`. Strips a leading `❯`.                                                                                                        |
| `sidebar/choice-prompt.ts`                | `samePrompt(a, b): boolean`                                                     | True when the option labels and their order are identical. The question text is ignored.                                                                                                                                                      |
| `sidebar/session-filter.ts`               | `matchesFilter(facts, text): boolean`                                           | Case-insensitive substring over name, workspace, project, branch, ticket key, ticket title and description. Empty text matches all.                                                                                                           |
| `sidebar/ledger-rows.ts`                  | `buildLedger(facts, prefs, filters): LedgerGroup[]`                             | Applies `hideExited`, the Needs you filter and the text filter, then groups, then sorts within each group: needs-you then working/idle/exited, or most recent activity. Closed records form a final `Closed` group. Empty groups are omitted. |
| `sidebar/logbook-groups.ts`               | `buildLogbook(facts, filterText): LogbookGroup[]`                               | Group order is Needs you, Working, Idle, Exited, Closed. Empty groups are omitted. The headline is ticket title, else the description's first line, else `Add a description`.                                                                 |
| `sidebar/logbook-groups.ts`               | `suggestWorkItems(facts, projectIssue, mine, limit = 3)`                        | The project issue goes first when it differs from the session's own link. Then `mine`, excluding the current work item. Deduplicated by `tracker:key`. At most `limit`.                                                                       |
| `sidebar/wall-order.ts`                   | `placeWall(facts, prefs): WallPlacement[]`                                      | Returns one placement per open session, `{ sessionId, band: 'needs' \| 'rest', order: number, span: 1 \| 2 }`. The output array order is by `sessionId`, stable across state changes (R11). `band` is `'needs'` only when `pinNeeds`.         |
| `sidebar/home-prefs.ts`                   | `loadHomePrefs()`, `saveHomePrefs(p)`                                           | Missing, corrupt or partially-unknown input falls back field by field to defaults. `save` never throws.                                                                                                                                       |
| `sidebar/wall-prefs.ts`                   | `loadWallPrefs()`, `saveWallPrefs(p)`                                           | Same as `home-prefs`.                                                                                                                                                                                                                         |

`BellAndBusySource.derive` (in `sidebar/agent-state.ts`, changed): returns `'awaiting-input'` when `session.choicePrompt` is set or `bellCount > 0`. Closed still outranks both.
