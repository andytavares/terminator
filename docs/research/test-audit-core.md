# Core test suite audit

**Date**: 2026-10-12
**Scope**: every spec under `tests/unit/**` and `tests/integration/**`, except `tests/unit/extensions/**`, `tests/unit/main/extensions/**` and `tests/unit/packages/**` (audited separately).
**Rules applied**: Constitution Principle VI; ADR 095 (unreachable code is deleted, not tested; a dependency production always supplies is required); ADR 096 (payload rejection is tested once, by the channel table); the architecture audit's test policy (one factory instead of partial store mocks; database handlers against a real SQLite).

## Method

1. Pattern scan of every file in scope: registration-only cases (`it('registers ...')`), `toBeDefined()`-only assertions, snapshot use, `vi.mock` of a store module, `as unknown as` fragments standing in for typed data, payload-rejection cases (`invalid`, `VALIDATION_ERROR`, `rejects ...`), and `register*Handlers(...)` calls that leave out an argument.
2. Every hit read in full, with the production code it exercises and that code's callers (`git grep -n -w <name>`).
3. Files with no hit are `keep`. They were not each read line by line; a later pass may still find tautologies the patterns miss, mostly in the renderer component specs.

`cases` counts `it(`/`test(` lines with `rg -c '^\s*(it|test)(\.each\(.*\))?\(' <file>` before this change.
