# Core test suite audit

**Date**: 2026-10-12
**Scope**: every spec under `tests/unit/**` and `tests/integration/**`, except `tests/unit/extensions/**`, `tests/unit/main/extensions/**` and `tests/unit/packages/**` (audited separately).
**Rules applied**: Constitution Principle VI; ADR 095 (delete unreachable code, do not test it; require a dependency that production always supplies); ADR 096 (test payload rejection once, in the channel table); the test policy of the architecture audit (one factory instead of partial store mocks; database handlers against a real SQLite).

## Method

1. Scan every file in scope for patterns: registration-only cases (`it('registers ...')`), `toBeDefined()`-only assertions, snapshot use, `vi.mock` of a store module, `as unknown as` fragments that stand in for typed data, payload-rejection cases (`invalid`, `VALIDATION_ERROR`, `rejects ...`), and `register*Handlers(...)` calls that leave out an argument.
2. Read every hit in full, with the production code it exercises and the callers of that code (`git grep -n -w <name>`).
3. Mark files with no hit `keep`. We did not read each of them line by line. A later pass can still find tautologies that the patterns miss, mostly in the renderer component specs.

`cases` counts the `it(`/`test(` lines before this change, with `rg -c '^\s*(it|test)(\.each\(.*\))?\(' <file>`.
