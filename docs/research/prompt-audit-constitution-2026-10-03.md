# Prompt audit: the constitution (2026-10-03)

The constitution has little model-dated cruft. Its `MUST`s are normative vocabulary, not pressure language. `speckit-analyze` extracts "MUST/SHOULD normative statements" from this file (`.claude/skills/speckit-analyze/SKILL.md:119`), so they stay. The audit found two kinds of problem.

- Some wording restated a rule with extra emphasis. This PR fixes that (1.4.0 → 1.4.1).
- Some text has drifted from the repository. Those findings are proposed below and not applied, because each one changes a fact or a rule.

## Assumptions

- **Scope.** `.specify/memory/constitution.md`, as requested. The audit cites files that disagree with it. It does not edit them, except where noted.
- **Line numbers** refer to constitution 1.4.0 (`origin/main` before this PR).
- **Target model.** Claude Opus 5.5. Claude Code sessions and Foundry agents read this file. They run the `opus` alias (prior audit, `docs/research/prompt-audit-2026-09-24.md`).
- **Not applicable.** Groups 3 (tool descriptions) and 4 (request config). The file has neither.

## Proposed, not applied

Each of these changes a fact or a rule, so each needs your decision. They are independent.

**P1: C2, build script name**

```diff
- - **Extension compiled output** (`extensions/*/src/index.js`) is a build artifact generated by `scripts/build-extensions.js`.
+ - **Extension compiled output** (`extensions/*/src/index.js`) is a build artifact generated by `scripts/build-extensions.cjs`.
```

Also update the comment at `.gitignore:19`.

**P2: C3, isolation in both directions** (MINOR bump: adds a rule)

```diff
- - IPC channels introduced for an extension MUST be registered by the extension's own
-   handler file. Core `index.ts` may wire in that handler file, but MUST NOT contain
-   handler logic written for the extension.
+ - IPC channels introduced for an extension MUST be registered by the extension's own
+   handler file, through the Extension API. Core MUST NOT contain handler logic written
+   for an extension.
+
+ **The other direction**
+
+ - Core MUST NOT import from, call into, read the files of, or name a specific extension,
+   and a core spec MUST NOT dictate an extension's internals. Data crosses the boundary
+   only through the Extension API or a core-owned publication point.
```

**P3: C10, version constraints** (one option; the alternative is to pin the manifests)

```diff
- - All version constraints MUST be pinned — unpinned `latest` is forbidden in production.
+ - `package-lock.json` MUST be committed; `latest` and `*` ranges are forbidden.
```

**P4: C11, formatting gate**

```diff
  - **`npm run lint` MUST pass with 0 errors** before any session or PR is considered complete.
+ - **`npm run format:check` MUST pass** before any session or PR is considered complete.
```
