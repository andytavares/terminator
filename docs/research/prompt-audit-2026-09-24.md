# Prompt audit — 2026-09-24

The prompt surface is mostly clean. Every finding below with a proposed edit is now implemented, and ADR 059 records the decision. The one exception is F6. L4 superseded its fast-tier rung, so ladder rungs now run with no agent at all. L5 is the ADR itself.

## Assumptions

- **Scope.** The whole repository prompt surface, because the request named no scope.
- **Target model.** Deep-tier roles run Claude Code's `opus` alias (`extensions/foundry/src/index.ts:365-388`), which resolves to the latest Opus. That is **Claude Opus 5.5**, the session model of this operator. Fast-tier roles run `haiku`, which is **Claude Haiku 4.5**. If the operator pins a different deep model in Foundry's settings, the effort findings (F5) change with it.
- **No Anthropic SDK.** Nothing in the repo calls the Messages API. Every model call is a `claude` CLI session. Claude Code owns thinking configuration, fallbacks and refusal handling, not this code. The audit found no non-Anthropic provider markers.

### Checked and kept

- Every role prompt apart from the architect narratives: plain register, reasons attached, prohibitions tied to real mechanics.
- All 12 `rules/*.yaml`: positive statements, each with its reason.
- `brief.ts` and the `rung-output.ts` contract. The JSON skeleton pins a Zod-validated shape, so it stays as a format-pinning example.
- The `agent-context.ts` template: data only, with budgets enforced in code.
- The "Never" list in `extensions/foundry/CLAUDE.md`: real isolation policy (Constitution II).
- Fast-tier steps already get no `--effort` (`executor.ts:638-639`). Haiku 4.5 does not take one.
